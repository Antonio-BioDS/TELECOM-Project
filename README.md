# TELECOM-Project
Utilizando una base de datos con descriptores del tipo de contrato de clientes de una empresa de telecomunicaciones se desarrollo un modelo predictivo de abandono con Machine Learning.


El proyecto se divide en tres fases: 

-Análisis exploratorio de datos (EDA)
-Desarrollo y entrenamiento del modelo predictivo con Machine Learning.
-Informe final con las observaciones y conclusiones obetenidas.
